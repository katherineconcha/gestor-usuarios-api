# Administrador de Usuarios con JSONPlaceholder

## Objetivos de la Aplicación
Este proyecto tiene como objetivo presentar datos desde una API pública (JSONPlaceholder) utilizando `XMLHttpRequest` en JavaScript. La aplicación administra la información recibida a través de una clase de programación orientada a objetos y permite realizar las siguientes operaciones mediante una interfaz de botones:
* Listar los nombres de todos los usuarios.
* Buscar usuarios específicos y mostrar su información básica y de contacto.
* Extraer y mostrar información como direcciones y datos de la compañía.
* Ordenar alfabéticamente los nombres de los usuarios extraídos.
